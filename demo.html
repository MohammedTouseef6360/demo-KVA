BolKhata — Demo Recording Guide

Record the real app, not a mock. Open http://localhost:3000 (or your HTTPS deploy) in Chrome full-screen.

Quick start

  1. Clear site data (DevTools → Application) → Reload.
  2. Settings → turn Voice feedback ON, Cloud sync OFF.
  3. Settings → Demo Data — auto-runs the full tour (sales → collection → expense → inward → udhaar → Z-report → stock → home).
  4. Screen-record with Win+G / OBS while it runs (~10s).
  5. Then manually: voice overlay → demo chip → Confirm Sale → Udhaar → Remind → Reports → Scan Barcode.

Full timed script

See demo-script.md in the project root for the 90-second beat-by-beat script with voiceover lines.

Mic troubleshooting

  • Mic works on localhost or HTTPS only.
  • On a phone over LAN (http://192.168.x.x) the browser blocks the mic — use ngrok or the deployed HTTPS URL.
  • If the mic fails, demo chips still run the full flow.
